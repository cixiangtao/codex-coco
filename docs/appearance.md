# 外观模块

外观模块管理外部 Codex 的三层布景，与 Codex Coco 自身主题分开。默认停用；默认策略下启用只创建运行时，不启动、重启或修改其他应用。已保存的 opt-in 恢复策略见下文。

## 操作

2026-10-22：外观页沿用柔彩组件基线，拆分为“布景编辑 / 图片与预设 / 连接设置”。默认页将比例预览与当前图层参数并排；900px 以下上下排列。预览图层选择与参数面板同步，图库使用同一图层选择。保存栏保持可达，支持保存并应用、仅保存与放弃未保存修改。

图片、预设和连接面板保持挂载；切换标签页、切换图层与返回导航均保留当前草稿。三层配置与 revision 仍由页面持有；放弃修改只恢复保存值，不执行外部撤销。连接、启动、验证与撤销操作集中在连接设置，明确重启仍先确认。详见 [外观界面说明](surfaces/appearance.md)。

1. 在主窗口启用外观模块，为壁纸、主面板或侧栏导入图片。
2. 设置图层开关、位置、适配、透明度，或插画宽度、模糊和不透明度。
3. “仅保存配置”写入版本化模块配置；“保存并应用布景”明确连接本机端口并安装样式。
4. Codex 需要已启用远程调试。支持固定 `127.0.0.1:<端口>`（默认 9229），也可明确选择应用后自动分配端口并启动；不会自动重启 Codex。
5. 可检查连接、验证样式、显式撤销。更换端口前须撤销原端口的样式。

应用后每三秒通过宿主的普通任务同步窗口。繁忙时推迟，不绕开任务并发限制；不另建常驻守护进程。新窗口与重载后的页面会在下次同步恢复样式。退出或停用会停止同步、取消任务，并尝试移除自己安装的样式；无法确认清理时模块进入错误状态，不伪称已清理。显式“撤销布景”也可恢复当前端口上此前运行留下的样式。

## 隔离

- 图片按内容哈希复制到独立 `appearance-assets` 目录；原文件与两个旧项目目录不修改。配置和 IPC 使用图片 ID，不发送原始文件路径。
- 支持 PNG、JPEG、WebP、GIF、AVIF，每文件最多 25 MiB；检查文件字节类型、大小和完整性，拒绝路径穿越和 SVG。缩略图由桌面适配生成并限长。
- CDP 仅使用固定发现路径与固定 Runtime.evaluate 表达式。拒绝远程主机、凭据、端口错配、跳转、非页面调试地址和非 Codex 主页面。最多处理十个主窗口，响应有大小和时间限制。
- 使用 `codex-coco-appearance` 样式节点及独立观察器。撤销只删除本应用的节点和观察器，不改安装包、不停止其他主题工具。
- 原始 CDP 异常、页面标题、URL、图片路径不通过结果或诊断公开。菜单栏仅投影运行状态、目标数量和时间。

## 验收

`pnpm run verify:appearance` 启动独立临时 Electron 目标，具备 Codex 的三类 DOM 表面与独立调试端口；通过正式主窗口桥导入受控图片，验证三层应用、多窗口、重载、验证、撤销和停用清理。脚本只替换该次测试应用的系统文件选择器，不在产品代码引入测试数据分支。

脚本同时验证外观页三层参数与标签页草稿保持、放弃修改、切换不应用目标、默认/720×640 布局不横向溢出，以及明暗主题截图。仅保存不应用和预览拖动/方向键定位继续使用原断言。截图包括 editor-light、editor-dark、editor-compact、library-light、connection-light。

`pnpm run verify:packaged` 包含同样的打包应用验证。截图位于 ignored 的 `work/appearance-verification*`。这些结果证明当前受控表面上的合同，不代表当前真实 Codex 版本已完成验收。真正的 Codex 选择器随版本变化仍需显式验证。

二期整体进度见 [能力清单](phase-two.md)。

## 二期扩展

配置现为 v2，v1 迁移后保持固定端口、恢复关闭、预设为空。图库承接九个许可文件，按内容去重为八张图片；导入的自定义图片可以重选，删除只作用于副本，被图层或预设引用的图片拒绝删除。图库和导入缩略图通过异步原生缩略图接口生成，不在主线程完整解码后再缩小。最多展示 60 个图库条目，每张缩略图及整体结果都有限额。

本地组合预览可选择壁纸、主面板或侧栏，通过拖动和方向键定位；数值控件保留。预览只是比例模拟，目标窗口的实际验证另行执行。最多保存 12 组命名预设，预设包含图层配置，载入预设不改变当前调试端口。保存预设与应用保持分离。

可选择正式 Codex 的 macOS 应用包（bundle ID `com.openai.codex`），私有路径保存在 appearance-launcher.json，不通过 IPC 发送。启动支持固定端口或新分配的本机端口。普通启动发现应用仍在运行会拒绝；明确重启先提示保存工作，请求所选应用正常退出，等待后带调试参数启动，拒绝退出不会强制终止。自动恢复只重新连接，不自动启动或重启应用。

“启动后恢复已保存布景”默认关闭，保存后在下次 Codex Coco 启用/启动时生效。启用该策略后，连接失败按 3–60 秒退避；成功应用后按三秒检查样式内容校验值和实际计算样式，不反复发送未变化的图片。样式缺失、目标重载或新增窗口时重应用。当前运行中的同步使用上次明确应用的配置，单独保存的新配置不会跟随同步生效。

`verify:appearance` 已增加图库、命名预设、定位、计算样式、退出撤销和重启 opt-in 恢复验收。`verify:appearance-launcher` 在临时编译的独立 macOS 应用上验证原生选择、真实 open 启动与端口参数、运行保护及受控重启；退出请求在测试适配器拦截为受控进程终止，避免弹出自动化权限提示，不向真实 Codex 发送退出请求。

## 三层定位修复（2026-10-21）

三层使用各自的参照区域：壁纸固定覆盖整个窗口，cover/contain 和百分比定位保持 CSS 语义；主面板与侧栏插画分别锚定本区域的边缘。插画的 0/100 表示贴近两端，50 表示居中，其余数值使用原 Codex Skin 的四值靠边锚点。预览与实际注入共用同一定位函数。

每个区域只创建一个带 `data-codex-coco-surface` 的背景节点，不再同时向主面板和内部滚动视口绘制插画，也不占用目标的 `::before`。只对静态定位容器临时提供定位参照，保留既有 absolute/fixed 布局；背景不接收鼠标事件。壁纸按当前 `--color-surface`、旧 `--codex-base-surface` 或系统 Canvas 颜色处理透明度，打通已识别的窗口外壳与滚动视口背景。撤销恢复本次增加的全部标记，删除自己创建的节点及观察器。

新版侧栏优先识别 `[data-slate-sidebar-content]`，旧 `.app-shell-left-panel` 作为回退；主面板优先 `[data-app-shell-main-surface]`，缺少时才使用视口回退。请求的区域不存在或无尺寸时不能报告应用成功。侧栏收起导致区域不可用时，可打开侧栏后重试或显式撤销；撤销不要求主面板节点仍然存在。

本地预览模拟 1000 × 620 的逻辑窗口，图片尺寸、模糊和各区域一起同比缩放。拖动只在所选区域内开始，使用该区域的宽高计算移动量，保留抓取偏移，单击不会跳位；支持取消、松开和方向键。预览图片按资产 ID 缓存，切换预设、重新打开窗口与重启后按需恢复，不把上一张图当成新图。PNG 缩略图保留比例与透明通道，超过传输限额时继续缩小。

应用返回成功前检查样式内容、实际图层、几何边界、计算样式与鼠标穿透。关闭所有图层并应用会撤销现有效果。后台业务状态独立于当前任务，加载图片和同步期间不再清空已应用状态与图库；连接错误不会被读取预览掩盖。
