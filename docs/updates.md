# 应用更新

Codex Coco 只从公开仓库 [cixiangtao/codex-coco](https://github.com/cixiangtao/codex-coco/releases) 发现版本。宿主持有更新服务直到退出，业务模块不能代为更新应用；用量辅助工具中的 Codex CLI 升级保持独立。

## 用户流程

2026-10-28 用户选择免费长期自签名，并要求“自动检查并提示，点击一次更新后下载并重启”。

- 首次从网络安装仍可能遇到 Apple 无法验证提示，按 [安装指南](../apps/desktop/resources/INSTALL.txt) 在隐私与安全性中为这个应用放行一次。自签名不能替代 Apple Developer ID 或公证。
- 新安装启动约十秒后检查，之后每 24 小时检查。检查只读公开版本信息，不下载、不重启。自动检查可在设置中关闭；已有版本 2 配置中保存的手动模式或自定义间隔保留，旧自定义源迁移仍关闭检查。
- 主窗口各页面都展示可用更新提示。点击“更新并重启”即同意该次任务下载、校验、安装和重启，界面在按钮附近说明后果；不用再次分别确认。请先保存工作。
- 下载可取消，取消等待底层任务实际结束；失败、取消、应用退出都不继续安装。普通退出不自动安装。现存独立下载和安装 IPC 动作仍要求显式确认，不由后台检查调用。

## 版本与频道

稳定版只请求匿名 GitHub REST `releases/latest`，只接收稳定版。项目预览版请求 `releases?per_page=100`，从最近一百项中选出最高的有效项目预览或稳定版。草稿、其他预发布命名及不匹配的标签/预发布标记排除。支持 `X.Y.Z` 与 `X.Y.Z-preview.N`，可带 v 前缀；数字比较保证 preview.10 高于 preview.9，同核心稳定版高于预览版，不降级。

请求固定 HTTPS 地址，禁止重定向，不读取 GitHub 凭据或发送账号内容；超时 15 秒，响应最多 1 MiB。404 或没有适合频道的版本显示“尚无可用版本”，与已是最新版、网络/限流/解析失败分别处理。失败清除旧的可下载版本。

旧 preview.1 只查稳定版，需要手动升级一次到新版；新逻辑不能改变已经安装的旧代码。新版起接收后续项目预览更新。GitHub 发布列表的协议见 [Release API 文档](https://docs.github.com/en/rest/releases/releases#list-releases)。

## 下载与原生安装

按需加载 electron-updater 6.8.9。检测不要求签名，打开版本页的链接只由受限标签构造；应用内下载与替换要求打包的 macOS 应用通过固定项目证书和 bundle identifier 的完整校验。未签名与任意其他自签名不符合要求。

检测保存本次选中的受限版本页；下载时用 generic provider 读取**这个具体 GitHub 标签**下的 preview-mac.yml 或 latest-mac.yml。用户不能提供自定义源或 URL。新发布不会在下载期间把目标换成另一版本；缺少元数据、元数据版本变化或无更新时拒绝下载。

预览发行从最终签名 ZIP 生成 preview-mac.yml，包含固定附件名、版本、SHA-512 与大小；JSON 表示是合法 YAML，由已锁定更新器解析。准备与发布阶段都核对内容，SHA256SUMS.txt 同时覆盖元数据。更新器执行下载校验；下载结束后宿主再次检查安装资格，由 Squirrel.Mac 验证包签名并替换、重启。DMG 主要用于首次手动安装。

## 配置、权限与隐私

updates.json 版本 2 只保存后台间隔和 revision。合法版本 1 自定义源迁移时移除源并关闭检查，保留文件直到明确保存或备份重置；损坏与未知版本不覆盖。保存有 revision 冲突检查与原子写入，重置先备份并恢复默认每日检查。

主窗口独占更新读写、打开发布页与操作入口，速览均无权限。下载期间不能改偏好。覆盖更新器的安装 UUID 请求头，不发送安装唯一标识；诊断排除发布正文、原始错误、账号和路径。

## 验证范围

合同覆盖频道选择、版本顺序、固定匿名 API、有界响应、错误/取消、自动检查不下载、手动策略保留、一键同意、取消/失败/退出不安装、签名门槛、配置/权限和私有错误排除。发行测试还用实际已锁定更新器解析生成的元数据，拒绝错误文件名、校验和、版本与外部地址。

真实 Electron 生产入口验证自动检查、手动模式、更新设置、跨页面提示和单次点击。界面一键按钮使用受控操作传输；宿主任务链由合同验证，没有让测试更新当前用户的应用。原生 Squirrel 同证书替换与拒绝篡改已在独立 runner 验证，两个公开 Codex Coco 版本间的完整端到端更新仍待签名发行后验收。
