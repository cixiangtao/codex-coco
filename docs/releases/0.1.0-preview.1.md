First public macOS Apple Silicon preview of Codex Coco.

## Included

- Codex CLI quota windows, optional local usage trends and explicitly confirmed tools.
- Three-layer Codex appearance controls, local images, presets and reversible CDP application.
- Menu bar summaries, animated icons, independent modules and light/dark/custom themes.
- GitHub Releases version checks and a pinned, self-signed update identity.

## Download and install

Choose the `macOS-arm64-self-signed.dmg` installer for an Apple Silicon Mac, or extract the ZIP. Move Codex Coco.app to Applications. Compare the file against SHA256SUMS.txt before opening it. THIRD_PARTY_LICENSES.txt and release-manifest.json describe dependency notices and the source commit.

This build uses a project-owned self-signed certificate. It is **not Apple Developer ID signed or notarized**. macOS can block the first launch; follow Apple's [instructions for opening an app from an unidentified developer](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unidentified-developer-mh40616/mac) only after verifying the download. No root certificate installation or global Gatekeeper changes are required by Codex Coco.

The current update checker follows stable Releases. This preview is intentionally excluded from that channel; future previews can be downloaded manually from Releases. The signing identity is retained for future native update continuity. No stable release or completed real-world update across two public Codex Coco versions is claimed.

## Scope

macOS arm64 only. Intel, Windows and Linux binaries are not included. Modules are disabled by default. Controlled tests do not replace acceptance using real accounts, actual Codex versions, reset-card consumption, OS login items or Widget registration. The Widget source is not an installed extension. The application currently uses Electron's default icon.
