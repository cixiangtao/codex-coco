Codex Coco preview with a compact menu-bar dashboard, a three-region appearance workspace and automatic packaging when a Release is published.

## What's changed

- The menu-bar popover groups the 5-hour and 7-day quota windows in one card with horizontal progress bars. Other selected information blocks remain independent cards, with compact daily usage and responsive half-width history cards.
- Drag cards directly to reorder the saved layout. Drag previews keep their original size and pointer position; keyboard sorting, narrow windows and reduced motion remain supported.
- Appearance editing now starts with one of three fixed regions. Open that region's image picker, choose an image and return to its parameters; presets expand in the toolbar and connection settings have a separate returnable page. Preview and parameters stay side by side at the supported window sizes.
- Settings are organized into tabs using the shared grouped-list controls.
- Appearance startup can connect to the selected running Codex app when the module starts. Explicit launch/restart and saved appearance application retain their confirmation and cleanup boundaries.
- Publishing a GitHub Pre-release now starts checks, self-signed packaging, independent verification and attachment upload automatically. Existing manual release controls remain available. Release provenance tests explicitly isolate their event context from the runner.

Preview.3 was withdrawn before any distribution artifacts were uploaded after a test inherited the runner's release event. This version includes that test fix and the same product changes.

## Install or update

Download the macOS arm64 DMG, verify SHA256SUMS.txt, and move Codex Coco.app to Applications. The project continues to use the same long-term self-signed identity. It is not Apple Developer ID signed or notarized; on first installation, macOS may require System Settings → Privacy & Security → Open Anyway. See the included Read Me First.txt.

Preview.2 can discover this version through its update checker. When the attachments are ready, click Update and Restart to authorize download, checksum/signature verification, installation and restart. Automatic checks never download or restart on their own. Preview.1 users need a manual upgrade because that version only checks stable releases.

The Release page appears before automatic packaging finishes. Wait for the DMG, ZIP, preview-mac.yml and checksum attachments before downloading or updating in the app.

## Scope

macOS Apple Silicon only. The release retains the existing opt-in business modules and private-data boundaries. Controlled tests and signed-package smoke checks do not establish real-account operations, current external Codex compatibility, Widget registration or a completed update between two public Codex Coco versions. No new performance baseline is claimed.
