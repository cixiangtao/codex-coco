Codex Coco preview with a simpler update flow and its own app icon.

## Install once

For Apple Silicon Macs, download the DMG, move Codex Coco.app to Applications, try opening it, then approve it in System Settings → Privacy & Security → Open Anyway. This free self-signed build is not Apple Developer ID signed or notarized; the first-launch Apple warning remains. The DMG includes Read Me First.txt in English and Simplified Chinese. No root certificate or global Gatekeeper change is required.

Users of preview.1 must download this version manually once: that older checker only follows stable releases. Starting with this version, preview installations can discover later previews and stable releases in the app. Stable installations continue to exclude previews.

## Update in the app

- New installations automatically check about ten seconds after startup, then daily. Checks only fetch public version metadata; they never download or restart by themselves.
- A notice appears across main-window pages when a newer version is available. Click Update and Restart once to download, verify and restart Codex Coco. Canceling or failing a download does not install it. Save your work before clicking.
- Existing saved manual-check preferences remain manual. Automatic checking can be switched on or off in Settings.
- The download is pinned to the release shown in the notice. The package checksum and native signature are verified; normal application quit does not automatically install an update.

## Identity and scope

This preview includes the original double-C logo in Finder/Dock, the installer, window title and About dialog. It retains the same long-term signing identity as preview.1.

macOS arm64 only. No paid Apple certificate, notarization, registered Widget extension or automatic download is included. Local controlled tests do not establish a completed update between two publicly released Codex Coco versions.
