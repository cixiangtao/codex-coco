# 用量与菜单栏速览 · 柔彩仪表台

模式：Operate。维护者在主窗口查看完整额度与本机趋势，在菜单栏快速查看跨模块摘要。核心任务是判断剩余额度、恢复时间与异常，并进入明确的恢复操作。

用户已选择 [A 样稿](../design/instruments-approved.png)，明确要求保留圆环与更圆润的圆角、进一步压紧布局，并先封装 Card/Box。该修改授权优先于样稿中的冗余进度条、留白和示例数据。批准来源及原始提示词保存在同目录 JSON。

首屏：保留既定图标侧栏与共同外壳背景；简短页头、标签页、双额度仪表、计数摘要与每日图表。辅助工具、重置卡和用量偏好不再与总览混排。最小窗口允许纵向滚动，禁止横向溢出。标签页保留未保存草稿，切换不启动读取或付费工具。

2026-10-22 精修：刷新与读取状态贴近页头操作，账号/套餐归入订阅额度区。额度卡以圆环为主，已用比例为短标识，恢复时间同时提供近似相对时间与准确时间。今日/7 天/30 天摘要与每日柱图归为同一活动表面，保留来源、范围和明细入口。

悬浮窗使用同一套容器与圆环，原生上限 360×520，按屏幕可用工作区收缩，底部主窗口入口始终可达。核心额度和计数优先，其他模块为紧凑摘要行；错误先于普通摘要。保持只读投影，不显示示例色板或引入模块配置、图片路径与业务结果。

悬浮窗使用结构化的公开账号标签与套餐建立身份条；额度与本机消耗分别使用清晰的信息块，前者提供恢复时间和新鲜度，后者使用柔彩数值单元。统计组统一声明 tokens，重置卡等辅助指标单独展示，不混入 tokens 单位。普通模块归入一个紧凑列表，错误独立突出。多额度按公开组名归属并允许滚动；到达恢复时间只提示刷新，不确认额度已恢复。显示时钟只在浮窗可见时运行，不触发源读取。

动效：圆环在数值变化时平滑更新；速览显示时短暂位移与淡入，保持正文稳定。不添加常驻装饰动画。减少动态设置必须生效；任务、取消、失败、缓存及停用行为沿用既有合同。

验收矩阵：980×800、720×640、浅色、深色、极端自定义主色、360×520 速览、初始停用、真实零值、失败与历史记录折叠、只读权限、键盘标签页与草稿保留。仅使用临时数据与受控 CLI。

主面板信息块可加入速览，用户在设置中选择、排序和预览；相邻同类块组合，其他块按保存顺序显示。主要额度、其他额度、今日/7/30 天消耗、每日趋势、重置卡与两种模块状态属于第一版公开块目录。图表提示卡展示结构化计数，不通过浏览器原生 title 承载主要信息。

悬浮主面板直接拖动信息块，取消独立排序页和顶部排序入口。实际额度、计数、趋势与状态旁使用共享 icon-xs 手柄（24px），松手自动保存；横排信息块使用竖向插入线、纵排块使用横向插入线（2px）。卡片跳转和数据文本保持原交互。键盘方向键与 Home/End、失败重试/恢复、冲突重载仍可达；底部始终保留主窗口入口。主题、紧凑分组与来源生命周期不随排序变化。
