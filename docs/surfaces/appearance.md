# 外观 · 布景工作台

模式：Operate。沿用已批准的柔彩仪表台组件世界，以当前区域的选图和调节为核心组织工作台，不改变外部 Codex 的布景合同。

主要任务是选择区域、换图、调整位置与样式、检查比例预览，再明确保存或应用。工作台工具栏固定显示全局壁纸、主面板插画和侧栏插画三个区域入口；当前区域同步决定预览描边、拖动范围与参数面板。默认 980×800 和最小 720×640 窗口都保持预览与参数双列；900px 以下压缩预览、参数列至少 240px、列间距 12px。三层草稿由父页面持有，切换区域保留各自修改。

当前区域的缩略图打开选图 Dialog，打开即载入内置与已导入图片，并显示加载、空状态或可重试错误；无需先进入独立图库页。选中后关闭并回到当前区域，取消不修改图片。导入可以从区域参数或 Dialog 发起，完成时只更新发起区域的图片并开启该区域，合并到最新草稿，保留等待期间的其他编辑。Dialog 关闭后将焦点交回当前区域入口；删除只作用于已导入副本，未保存草稿和仍被引用的图片保留原有保护。

“布景预设”在工具栏下内联展开。收起、切换区域或进入连接设置保留预设名称与草稿；载入替换三个区域的草稿并收起面板，保留当前连接偏好。连接设置通过页头入口进入，顶部提供“返回布景编辑”；编辑与连接面板保持挂载。连接页先展示目标应用、启动/重启与检查/恢复动作，再展示启动偏好；端口置于默认折叠的“高级连接设置”，自动模式隐藏固定端口输入。导航不自动启动或应用，连接检测仍由宿主按启用、聚焦与速览可见生命周期触发。

Card 提供统一标题、说明、表面与圆角，Box 管理布局，参数复用 SettingsGroup / SettingsRow / Switch。连接状态条的“Codex 中已有布景”描述外部当前效果，底部保存栏另行显示未保存修改或已保存待应用。保存栏粘附于内容滚动区，提供保存并应用、仅保存、放弃修改和当前任务状态；仅保存保留 Codex 原有效果，放弃修改只恢复已保存配置。错误与冲突提示在编辑和连接视图中都可见，明确重启仍经过确认弹窗。

预览沿用 1000×620 逻辑几何、共享定位函数和按区域拖动换算，不把主面板与侧栏改成独立示意卡。图片使用已有图库缩略图与本地受控导入，保留比例、透明度及来源许可；不新造装饰素材，不暴露本地路径。自定义主色只影响 Codex Coco 控件，不改变外部布景配置。

验收范围：980×800、720×640、明暗主题、双列编辑/选图 Dialog/内联预设/连接子页，图库自动载入及失败重试、空状态、选择与取消、导入期间草稿合并、三层切换及参数保持、预设名称保持、预览键盘与拖动、固定/自动端口显示、放弃草稿、仅保存不应用、明确重启取消、错误恢复、三层目标像素与退出清理。仅操作临时 Electron 目标，不操作真实 Codex；本轮执行结果以 [验证记录](../verification.md) 为准。

启动/重启明确操作自动接续应用与验证已保存布景，页面顶部和速览根据连接状态提供恢复入口。启动反馈区分已连接与布景已应用；所有图层关闭时不宣称应用成功。
