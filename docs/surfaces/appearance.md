# 外观 · 布景工作台

模式：Operate。沿用已批准的柔彩仪表台组件世界，补齐外观页的视觉一致性，不改变外部 Codex 的布景合同。

主要任务是选择图层、调整位置与样式、检查比例预览，再明确保存或应用。默认“布景编辑”将预览与当前图层参数并排；900px 以下改为上下排列。图层选择同时控制预览定位区域与参数面板，三层草稿由父页面持有。图片与预设、连接设置进入独立标签页，切换保留草稿，不自动启动或应用。连接检测由宿主按启用、聚焦与速览可见生命周期触发。

Card 提供统一标题、说明、表面与圆角，Box 管理布局。底部保存栏粘附于内容滚动区，始终提供保存并应用、仅保存、放弃修改和当前任务状态。错误与冲突提示跨标签页可见，明确重启仍经过确认弹窗。

预览沿用 1000×620 逻辑几何、共享定位函数和按区域拖动换算，不把主面板与侧栏改成独立示意卡。图片使用已有图库缩略图与本地受控导入，保留比例、透明度及来源许可；不新造装饰素材，不暴露本地路径。自定义主色只影响 Codex Coco 控件，不改变外部布景配置。

验收：980×800、720×640、明暗主题、编辑/图库/连接各标签、空图库、图片选择与导入、三层切换及参数保持、预览键盘与拖动、放弃草稿、仅保存不应用、明确重启取消、错误恢复、三层目标像素与退出清理。仅操作临时 Electron 目标，不操作真实 Codex。

启动/重启明确操作自动接续应用与验证已保存布景，页面顶部和速览根据连接状态提供恢复入口。启动反馈区分已连接与布景已应用；所有图层关闭时不宣称应用成功。
