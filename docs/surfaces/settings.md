# 设置 · 分组列表

模式：Operate。2026-10-22 用户要求参考 iOS 设置页的 Field Group，改善其他表单设置的简陋感。保持 Codex Coco 的柔彩与圆润基线，将同类设置组织为圆角列表，组标题与辅助说明放在表面之外，组内细分隔线。

SettingsGroup / SettingsRow / Switch 属于 UI 包：分组只处理表面和语义，设置行提供行内与展开两种排列；标签、说明在左，简单控件在右，复杂输入在下方展开。开关表达二选一，多选项继续使用分段选择，避免把每行都做成按钮组。小窗口的开关仍靠右，复杂选择和文本输入可以上下排列。

当前接入窗口主题与关于、应用更新、系统与菜单栏、模块管理、用量偏好及辅助工具/重置卡，以及外观连接、图层参数、图库与预设。保留宿主控制的草稿、保存、取消、冲突和权限边界；切换开关不直接修改系统登录项、共享文件、真实外部布景或应用安装。需确认的系统操作继续单独确认。

用量偏好按刷新与本地记录、额度通知、菜单栏显示分组；复杂控件使用原有 FieldLabel / FieldDescription 和输入关联。默认、禁用、焦点、键盘、明暗、极端主色和 720px 下必须可操作，不将隐藏的 checkbox 当作需要展开的文本输入。

跨页面按用途分组，不能只替换用量页控件：系统设置分为菜单栏图标、动画与性能、系统集成；图标选项区域有界滚动，保存动作位于完整偏好之后，应用系统配置仍是独立确认。模块管理把名称、状态与启停放在同一行，故障保留恢复入口。外观图库/预设使用相同分组表面，图像网格保留真实选择语义；样本检测、检测历史、CLI 维护和重置卡分别成组，不自动读取或执行。

速览设置采用同样的分组行，已选块支持上移/下移与移除，可选块提供添加。右侧公开预览复用真实速览组件；小窗口移到列表下方。预览仅在设置页可见时接收公开数据，草稿在切换页面时保留，实际悬浮窗跟随已保存组合。
