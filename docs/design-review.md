# Codex Coco 窗口方案评审

日期：2026-10-21。状态：**精简侧栏已获认可并接入正式主窗口；此页继续记录独立合成数据评审工具，配色细节仍可打磨。**

## 已确认的使用方式

主窗口提供所有模块的主要能力。用量通常通过菜单栏悬浮窗快速查看，外观与设置主要在主窗口操作。悬浮窗是跨模块的速览入口，不专属于用量模块；各模块可以贡献摘要和进入主窗口的入口。

用量更新失败时，优先展示异常和恢复操作。旧数据默认收起，用户主动展开后才能查看，并标明上次更新时间与数据过期提示。

## 查看与比较

在仓库根目录执行：

```sh
pnpm run design:review
```

打开 <http://127.0.0.1:5190/>。服务只监听本机。`pnpm run design:build` 将独立预览构建到被 Git 忽略的 `work/design-review/`。

| 方案           | 窗口组织                               | 主要取舍                                 |
| -------------- | -------------------------------------- | ---------------------------------------- |
| A · 精简侧栏   | 常用模块在上，管理和设置在下；支持折叠 | 内容优先，保留模块扩展入口               |
| B · 顶部导航   | 低层级导航放顶部，内容横向展开         | 少量模块轻巧；模块多时需要进一步收纳     |
| C · 工具台分栏 | 窄导航、内容区、常驻状态栏并排         | 状态便于对照；增加信息密度，窄窗口需重排 |

三者复用相同页面、语义 token 和共享控件。用户认可侧栏方向，提出参考 Codex 客户端布局并精简侧栏；当前默认展示 A，B/C 保留为对照，字号、间距与正式配色仍可继续调整。

A 的侧栏上方只放用量与外观，下方放模块管理与设置；移除工作空间标签、模块启用数量、本地运行提示和窗口底部的重复说明。标题栏与侧栏采用连续表面，展开宽度 168 像素，折叠为 56 像素图标栏。折叠后保留可访问名称、悬停提示和当前页面状态；窄窗口改为带文字的横向导航。评审页外部继续明确合成数据边界。

评审页可以：

- 在用量、外观、模块、设置之间切换，查看完整窗口组合。
- 切换浅色/深色并输入自定义 HEX 主色；无效输入标记为错误，保留最近有效颜色。
- 比较正常、未连接、更新失败、多账号长文案四种用量状态。
- 预览三种合成布景，只改变页内示意画面。
- 在设置中选择悬浮窗展示的模块，查看跨模块速览和空选择状态。
- 从悬浮窗进入对应主窗口页面；通过菜单栏入口开合浮窗。

页面外侧的评审控件与提示不属于未来产品窗口。皮肤预览里的外部 Codex 界面是结构示意，不能作为外部应用的精确截图或适配证据。

## 实现边界

独立入口位于 `apps/desktop/src/renderer/design-review/`，使用单独 Vite 配置。正常 Electron 入口已独立实现精简侧栏和真实设置，不导入此评审入口；业务模块注册表保持为空。

所有账号、额度、恢复时间和同步状态均为合成数据。连接、刷新、重试等按钮只反馈示意文案；模块开关、布景预览和浮窗偏好仅在当前评审页的 React 状态中生效，刷新后重置。未读取凭据、调用桌面桥、发起用量请求、写入应用偏好或修改外部 Codex。

主题依然复用 `packages/ui` 的受控 Provider；基础按钮、表单、输入、Alert 和 ToggleGroup 复用共享组件。`cn` 和 Lucide 从桌面包直接声明的精确版本依赖导入，没有新增工具封装。

## 本轮检查

真实浏览器使用本机 Chrome 的独立自动化上下文，检查三个方向的明暗主题、主色输入、用量异常折叠、跨模块浮窗配置与主窗口跳转；检查 1280、720 和 390 像素宽度的布局，其中 390 像素是额外的窄屏压力检查，不是移动端适配承诺。浏览器检查过程没有页面异常或发往本地服务以外的请求。

截图与临时检查脚本在被 Git 忽略的 `work/design-review-verification/`。工程检查使用 `pnpm run check`；评审产物另用 `pnpm run design:build` 检查。这里的浏览器结果不能替代未来正式接入后的 Electron 菜单栏、焦点管理、屏幕边缘定位或多窗口回归。

本轮精简额外检查了默认 A、上下导航分组、键盘折叠/展开、图标栏下四个页面的可达性、明暗主题及主色，以及 980/720/390 像素宽度。通过临时 Electron 44 窗口加载独立评审页，在 980×800 窗口中检查折叠、设置跳转与渲染隔离；使用临时数据目录，结束后关闭并清理。该检查未接入正式窗口壳或真实菜单栏。

正式窗口壳已落地，实际布局与交互见 [界面基线](../DESIGN.md) 和 [主窗口](main-window.md)。菜单栏跨模块摘要和业务仍待接入；评审页的示意状态不代表正式能力。
