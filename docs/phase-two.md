## 验证原则

- 凭据始终留在后台或由 CLI 管理。原始账号、令牌、模型输出、私有路径和对话不得进入公共诊断与菜单栏。
- 自动刷新必须显式开启，默认不读账号；停止、取消、退出都等待资源实际释放。
- 趋势扫描使用工作线程，只保留计数元数据，不把聊天文本发给任何服务。
- 对外观应用使用受控的临时 Electron 页面做验收，不代用户操作当前正在聊天的 Codex。
- 每批通过合同测试和相关真实 Electron 验证后自动本地提交，不推送、不发布。

## 核心实现与交付验收

清单中的“已接入”表示有实现入口，不表示与旧项目完整等价。用户实际测试已发现能力缺失与状态耦合问题；用量正在按 [行为对照](usage-parity.md) 重新核对与修复。2026-10-26 已补齐默认模型/强度、平均推理量和同模型历史基线比较；跨模块状态与恢复继续按具体行为验收，不能由测试数量推断所有旧能力完整等价。二期仍保留真实环境验收项：真实账号的额度与模型请求、真实重置卡消费、真实 CLI 升级、真实 Codex 版本的 DOM 与重启、macOS 登录项、签名更新和 Widget App Group 注册。受控验证不替代这些结果，不代用户自动执行会影响当前工作或消费额度的操作。

Widget 沿用旧项目的原生源码交付层级，没有伪装成已注册扩展。2026-10-28 已按用户授权配置 GitHub 发布源并发布长期自签名预览；没有 Apple Developer ID 或公证。UI 当前以功能可操作为目标，视觉统一后续进行。
