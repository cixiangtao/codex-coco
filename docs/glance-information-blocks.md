# 自定义速览信息块

2026-10-22：主窗口的信息区可以添加到菜单栏速览；设置页提供组合编辑和公开数据预览。信息块是展示单元，不是另一个后台业务模块。

## 使用

额度窗口、今日/7 天/30 天消耗、每日趋势、重置卡、外观与系统状态区提供添加/移除图钉入口。图钉直接保存该项选择；设置里的编辑则是窗口本地草稿，支持添加、移除、上移、下移、取消和恢复默认组合，点击“保存速览组合”后才更新实际窗口。

默认组合保留两个额度窗口、三项本机消耗与外观/系统状态。相邻且同类的信息块自动组合；分开排列则分别展示。更多内容在正文内滚动，底部主窗口入口固定。空组合保留添加指引；停用或缺少数据时显示不可用状态，不显示伪造的零值。来源异常仍优先展示恢复入口，即使对应信息块没有被选中。

悬浮主面板中的信息块直接提供拖动手柄，不需要切换排序页或点击完成。拖动实际圆环、计数或状态旁的手柄，在目标信息块放下后自动保存并同步主窗口；横排额度和计数按目标左右半部、纵排块按上下半部判断落点，主色插入线指示位置。相邻同类块仍按保存顺序组合。聚焦手柄后，也可用上下方向键、Home/End 排序，每次有效移动自动保存。卡片里的跳转、按钮和文字不触发拖动。

拖出有效目标、拖动中取消或原生隐藏不保存移动；普通浏览时 Esc 收起面板。已经放下的移动独立完成保存，收起窗口不代表撤销。保存中暂时禁用排序手柄；失败保留当前排列，并提供“重试保存 / 恢复原顺序”。少于两项不显示手柄，配置不可编辑时禁用手柄。添加、移除与配置恢复仍在主窗口操作。

## 合同与扩展

`contracts/glance-layout.ts` 的静态注册表提供稳定 ID、所属模块、公开名称及固定主窗口页面。第一版共有九个可选信息块；添加新块需要登记合同及紧凑展示实现，并在对应主页面放置入口。共享 UI 包只提供 Card、Tooltip 等基础控件，不能依赖此注册表、IPC 或业务数据。

`GlanceBoard` 同时渲染实际悬浮窗与设置预览。主窗口保留完整编辑布局；两个表面共享业务模块已经读取的公开数据，不复制主页面 DOM，也不为每块启动扫描、轮询或后台生命周期。每日趋势额外投影最多七个日期与数值，以及估算/不完整标识；不投影文件、会话、对话或账号响应。

## 存储与窗口权限

宿主持有独立 `glance-layout.json`，版本 1，只保存受限 ID 的有序数组。复用原子写入、0600 权限、revision 冲突检查、损坏/未来版本原文保护与显式备份恢复。文件缺失时在内存使用默认组合，读取不自动落盘。保存成功后的窗口/原生通知失败不能撤销持久化结果或伪报保存失败，调用方仍获得已保存 revision。移除块不停止模块，停用模块也不删除用户排列。

完整配置读取、保存、恢复及公开摘要预览 IPC 仍仅主窗口开放。`GlanceSnapshot` 额外提供排列 revision 与可编辑标记，业务数据仍为公开摘要。唯一新增写入是仅悬浮窗可用的 `reorderGlanceLayout`：strictObject 校验受限 ID、无重复、与当前选择完全相同的集合，再以 revision 原子保存；不能增加/删除信息块、恢复配置或执行业务任务。主窗口修改组合时，未保存的失败排列不能覆盖新组合，提供“载入最新顺序”；正在拖动的旧 revision 不会发起保存。保存失败保留草稿供重试，持久化成功后的通知异常仍不伪报失败。

预览只在设置页面可见时订阅公开摘要，草稿不广播；其他窗口保存后保留本地草稿并提示冲突。显示时钟仍由窗口统一持有，不由每个信息块各自启动。排序不读取或刷新来源模块、不增加后台轮询。

`pnpm run verify:glance-layout` 使用临时数据验证选择、排序、草稿/取消、跨窗口冲突、受限权限、源页面图钉、重启及备份恢复；通过真实鼠标直接拖动、键盘/Home/End、自动保存与主窗口同步、排序集合校验、无效落点/失焦、保存冲突及磁盘失败重试验证交互。可用 `node scripts/verify-glance-layout.mjs --packaged` 验证本地未签名包；所有模块保持停用，不访问真实账号。
