# 自定义速览信息块

2026-10-22：主窗口的信息区可以添加到菜单栏速览；添加和移除通过功能面板图钉完成，排序直接在悬浮主面板进行；设置页不再提供重复编辑入口。信息块是展示单元，不是另一个后台业务模块。

## 使用

额度窗口、今日/7 天/30 天消耗、每日趋势、重置卡、外观与系统状态区提供添加/移除图钉入口。图钉直接保存该项选择，并同步所有窗口；无需进入设置页或再次保存。

默认组合保留两个额度窗口、三项本机消耗与外观/系统状态。2026-11-04 起，每个已选信息块对应一张独立 Card；按已保存顺序单列排列，不再按相邻类型合并或拆开卡片。更多内容在正文内滚动，底部主窗口入口固定。空组合保留添加指引；停用或缺少数据时显示不可用状态，不显示伪造的零值。来源异常仍优先展示恢复入口，即使对应信息块没有被选中。

每张 Card 的标题区提供 24px 拖动手柄，不需要切换排序页或点击完成。拖动时整张卡片沿纵向保持原尺寸和抓取位置，限制在正文可视范围内，原列表提供等高占位，相邻卡片通过 160ms 位移让位；松手立即放入目标位置并自动保存。使用 `@dnd-kit/core` 的指针传感器与 `DragOverlay`、sortable 的单列策略；移动超过 6px 才开始拖动，不使用操作系统拖拽缩略图。结束时不再播放一段回到旧位置的预览动画，避免异步保存造成双影。正常保存不重建整列 Card。拖动期间固定本次公开数据，后台刷新不会改变卡片高度。

账号、套餐与新鲜度归入上方身份条；每张额度卡同时展示圆环、额度窗口和两种恢复时间，每张本机消耗卡独立展示名称、主数值、tokens 单位和来源/完整性说明。状态、重置卡与趋势各自成卡。额度与本机数据的归属口径保持原合同，缺失计数不显示零。

有效落点只在正文可视区内；拖向上下边缘时自动滚动，固定工具栏和底部动作不接收放置。聚焦手柄后可用上下方向键、Home/End 排序。键盘移动后恢复焦点并使其可见，鼠标保存不主动跳转滚动位置；卡片内的跳转、按钮和文本不启动拖动。减少动态效果关闭相邻卡片的位移动画。

拖出有效目标、拖动中取消或原生隐藏不保存移动；普通浏览时 Esc 收起面板。已经放下的移动独立完成保存，收起窗口不代表撤销。保存中暂时禁用排序手柄；失败保留当前排列，并提供“重试保存 / 恢复原顺序”。少于两项不显示手柄，配置不可编辑时禁用手柄。添加、移除与配置恢复仍在主窗口操作。

## 合同与扩展

`contracts/glance-layout.ts` 的静态注册表提供稳定 ID、所属模块、公开名称及固定主窗口页面。第一版共有九个可选信息块；添加新块需要登记合同及紧凑展示实现，并在对应主页面放置入口。共享 UI 包只提供 Card、Tooltip 等基础控件，不能依赖此注册表、IPC 或业务数据。

`GlanceBoard` 渲染实际悬浮窗，`GlanceBlockCard` 同时提供正常卡片和不可交互的整卡拖动预览，使用业务模块已经读取的公开数据，不复制主页面 DOM，也不为每块启动扫描、轮询或后台生命周期。每日趋势额外投影最多七个日期与数值，以及估算/不完整标识；不投影文件、会话、对话或账号响应。

## 存储与窗口权限

宿主持有独立 `glance-layout.json`，版本 1，只保存受限 ID 的有序数组。复用原子写入、0600 权限、revision 冲突检查、损坏/未来版本原文保护与显式备份恢复。文件缺失时在内存使用默认组合，读取不自动落盘。保存成功后的窗口/原生通知失败不能撤销持久化结果或伪报保存失败，调用方仍获得已保存 revision。移除块不停止模块，停用模块也不删除用户排列。

完整配置读取、保存、恢复 IPC 仅主窗口开放；设置预览专用 IPC 已随编辑器删除。`GlanceSnapshot` 额外提供排列 revision 与可编辑标记，业务数据仍为公开摘要。唯一新增写入是仅悬浮窗可用的 `reorderGlanceLayout`：strictObject 校验受限 ID、无重复、与当前选择完全相同的集合，再以 revision 原子保存；不能增加/删除信息块、恢复配置或执行业务任务。主窗口修改组合时，未保存的失败排列不能覆盖新组合，提供“载入最新顺序”；正在拖动的旧 revision 不会发起保存。保存失败保留草稿供重试，持久化成功后的通知异常仍不伪报失败。

主窗口图钉跟随已保存选择同步；并发保存仍核对 revision，旧请求不能覆盖新组合。配置损坏或来自更新版本时，主窗口统一显示备份恢复提示，正常状态不显示额外编辑区。显示时钟仍由窗口统一持有，不由每个信息块各自启动。排序不读取或刷新来源模块、不增加后台轮询。

`pnpm run verify:glance-layout` 使用临时数据验证设置编辑区移除、选择保留、排序、跨窗口冲突、受限权限、源页面图钉、重启及跨页面备份恢复；通过真实鼠标逐步拖动、整卡预览尺寸与抓取点、边缘滚动、减少动态效果、键盘/Home/End、自动保存与主窗口同步、排序集合校验、无效落点/拖动中失焦、拖动中选择改变、保存冲突及磁盘失败重试验证交互。可用 `node scripts/verify-glance-layout.mjs --packaged` 验证本地未签名包；所有模块保持停用，不访问真实账号。
