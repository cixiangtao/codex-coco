## 实现原则

- 先满足个人日常流程，不追求一次复刻旧项目全部功能。
- 按新合同编写代码和测试，不为原型目录或接口添加兼容层。
- 若复用来源代码、测试或资产，同步更新许可证和来源记录。
- 新应用外观默认关闭，不自动导入凭据或接管旧守护进程。
- 原型数据和两个旧仓库不在清理范围内；未来导入需明确来源、差异和恢复方式。
