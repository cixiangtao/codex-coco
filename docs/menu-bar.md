# 菜单栏与跨模块速览

日期：2026-10-22。状态：原生菜单栏入口、公开摘要悬浮窗、受限排序、布景快捷操作和主窗口跳转已实现；用量同步后台公开额度，外观提供连接与同步状态摘要。当前采用柔彩圆环与紧凑摘要行，首期验证 macOS arm64。

## 使用方式

应用运行后，菜单栏默认只显示单色模块网格图标；有可用的用量摘要时附加简短数据（例如 `5h 75% · 7d 40%`），无摘要、异常或停用用量模块时只保留图标。完整名称 Codex Coco 保留在悬停提示、菜单和主窗口中。启用“系统与菜单栏”后可选原生或自定义图标、GIF、逐图速度与按需 CPU 联动；停用清理动画和采样计时器。单击开合速览，右键菜单可打开主窗口、用量、外观、设置或退出。应用菜单中的“显示或收起速览”使用同一路径，并提供局部快捷键 Cmd+Shift+M。

速览失去焦点、按 Esc 或点击关闭图标时收起。关闭全部主窗口后，仍可从菜单栏进入；点击模块或设置入口，会复用最近聚焦的主窗口，必要时新建一个。窗口最小化时会恢复，主窗口中未保存的主题草稿保留。普通“打开主窗口”保留已有页面；没有主窗口时默认进入外观。

拖动时 Esc 取消本次手势，普通浏览时 Esc 收起窗口；松手后自动保存，不需要进入排序页。原生 show/hide 通过仅发送给该速览窗口的 boolean 事件同步显示状态；renderer ready 额外同步当前值，覆盖可见窗口重载。macOS panel 隐藏后 document.visibilityState 可能仍为 visible，因此拖动清理和显示时钟不依赖这个 DOM 状态。

用量默认停用，明确读取后速览显示额度窗口、剩余比例、恢复时间和读取时间。刷新期间保留明确标注的最近记录；取消或辅助工具失败不清除成功额度。服务额度读取失败时隐藏旧额度，优先跳转用量页恢复。外观显示连接、同步与恢复状态。已注册模块加入阶段摘要，启停在模块管理中操作。速览显示已脱敏账号、套餐、今日/近 7 天/近 30 天计数与可用重置卡摘要。刷新按钮重新读取宿主摘要，同时可触发已启用外观模块的本机连接检测，不刷新账号或访问外部网络。支持在主窗口选择信息块及排序，详见 [自定义速览](glance-information-blocks.md)。

## 结构与生命周期

`desktop/main/menu-bar.ts` 持有一个 Tray 和一个延迟创建的 360×520 悬浮窗。首次点击才创建渲染窗口，收起后复用；窗口被关闭或销毁后，下次打开重新创建。快速开合的意图在 renderer ready 前也有效，加载完成不会重新弹出已取消的窗口。速览可见期间每 10 秒检查已启用外观模块的本机连接；隐藏或销毁后停止，不增加后台账号轮询。

额度使用共享 Card 与 ProgressRing，计数采用紧凑统计行；普通模块将图标、名称、状态和跳转放在一行，运行态必要说明最多补一行，错误保留原因与恢复入口。顶部采用完整名称，底部固定主窗口入口。更多额度组或受限工作区通过内容滚动承载，不缩小核心数字。圆环、表面和弹层随已保存主题变化，减少动态效果设置同时生效。

`glance-bounds.ts` 使用 Electron 的 DIP 坐标，从菜单栏锚点和显示器 workArea 计算位置；支持负坐标显示器、底部任务栏和受限工作区，必要时缩小窗口。显示器移除或工作区变化时重新定位。

原生入口使用内嵌 2× PNG 模板图标，不依赖开发/打包路径，不构成正式应用 Logo。退出时销毁 Tray、注销屏幕监听，再沿用原有模块停止、配置与日志排空流程。Tray 创建失败时记录固定错误码，主窗口仍可运行，应用菜单保留速览入口。实现参考 [Electron Tray](https://www.electronjs.org/docs/latest/api/tray)。

## 窗口身份与权限

主进程按 webContents 注册 main / glance 身份，不从 URL、DOM 或调用参数推断角色。两个窗口使用相同受限入口，不增加任意 URL 路由。

| 能力                               | 主窗口       | 速览窗口     |
| ---------------------------------- | ------------ | ------------ |
| 读取窗口身份、已保存主题           | 允许         | 允许         |
| 获取完整模块快照、启停、配置和任务 | 允许         | 拒绝         |
| 保存主题、恢复设置                 | 允许         | 拒绝         |
| 读取/订阅速览摘要                  | 公开预览接口 | 允许         |
| 跳转到既定主窗口页面               | 允许         | 允许         |
| 收起速览                           | 拒绝         | 允许         |
| 重排已添加的信息块                 | 使用完整编辑 | 仅同集合     |
| 布景启动/重启/应用快捷入口         | 使用模块任务 | 受限专用通道 |

新增方法通过固定白名单通道暴露。跳转输入使用 strictObject，仅允许四个 MainPage，或空对象表示打开已有主窗口；不接受 URL、文件路径或额外字段。完整模块事件仅推送给主窗口，速览仅收到公开投影。沙箱、主 frame、精确入口地址、CSP、外部导航和权限拒绝规则继续有效。

## 摘要合同

`contracts/glance.ts` 定义 id、公开标题、展示阶段、说明、主窗口目标、有限指标与读取时间。模块通过 BuiltinModule.glance 声明公开字段，ModuleHost 使用 strictObject、长度与条数限制校验；`application/glance.ts` 合成状态，不复制完整配置、任务结果、任务名或原始错误。指标包含稳定 ID、标签、展示值和说明，最多 40 项；可选 progress 限 0–100，numericValue 非负且不超过 Number.MAX_SAFE_INTEGER、unit 限 24 字符，用于圆环与紧凑格式化。不从文案反解析数值，不放宽私有字段限制。

未注册能力显示“尚未接入”。配置、运行时或任务生命周期异常优先，引导到模块管理；业务读取失败可使用模块自己的公开提示并回到主要页面。用量失败不向摘要发送历史额度或历史读取时间。接入合同见 [用量模块](usage.md)。

宿主为摘要维护独立单调 revision。仅展示内容变化时推送，任务的重复进度事件不会重复刷新相同摘要。客户端先订阅再读取，旧读取不能覆盖更新的事件；读取失败隐藏旧内容，提供重新读取和进入主窗口的入口。

速览只跟随已保存主题与系统明暗变化。主窗口未保存的预览不进入速览；保存后的广播才更新它。

2026-10-22 精修：成功用量在单一监视表面中显示公开身份、额度组、相对/准确恢复时间与本机统计；普通模块使用共同列表表面。投影新增可选 identity（仅已脱敏 label 与公开套餐 plan）、指标 group 和 resetsAt。identity 为 strictObject，字段限长；group 最多 120 字符，resetsAt 是非负、有限且可表示为日期的整数毫秒或 null。不得把原始账号响应、邮箱字段、令牌或路径补入结构。

相对时间只用于显示；达到恢复时间提示刷新，记录超过十分钟或恢复时间已到时，新鲜度改为警告。浮窗的 30 秒显示时钟只在可见时运行，隐藏或卸载时停止，不调用模块刷新。刷新速览可附带本机布景连接检测，不获取账号或外部网络数据。统计组统一标注 tokens，重置卡等不同单位指标单独显示。

## GIF 透明背景修复（2026-10-22）

IKUN同学反馈“只因篮球”为黑色主体并带黑绿背景。首帧的透明色索引为 196，全局背景索引为 255（绿色）；此前把索引不同当成不透明背景，将调色板背景画进逻辑画布，并在 disposal=2 清帧时再次填入。错误绿色还干扰单色判定，导致黑色主体没有交给系统模板着色。

合成现在从透明画布开始，disposal=2 清除上一帧范围的 RGBA；真实画在图片帧里的彩色背景仍保留。GIF 图形控制扩展可以跨过应用元数据与注释生效，先关联到下一张图片，再进行合成，避免 cat2 等素材首帧丢失透明索引和延迟。没有改动源素材，也没有把所有 GIF 强制变成模板。

新增 `pnpm run verify:tray-colors`：通过正式模块、worker 与 Tray.setImage 取得实际 2× 图片，使用 Chromium ImageDecoder 作为独立 GIF 解码对照。19 个内置 GIF 的首帧逐像素对照，篮球完整 17 帧与实际动画输出对照；透明像素的 RGB 忽略，可见 RGB 只允许色彩转换产生的 2/255 容差，alpha 必须一致。篮球首帧 36×36 中 1041 个透明像素，系统模板标记为 true；18×18 DIP 与动画每帧标记一并核对。

`work/tray-colors*/basketball-mask.png` 是实际生产 alpha 在明暗背景上的模拟对照，不是 macOS 菜单栏截图。该专项已纳入打包验证；系统壁纸、多显示器与辅助显示设置的真实菜单栏外观仍需独立验收。旧的 cat3/my0 固定模板预期已撤下，回归先以独立解码器核对正确像素，再检查篮球等单色主体与彩色图的模板策略。

自定义组合以版本化的独立文件保存，主窗口负责增删、完整编辑与恢复；悬浮窗只可重排已添加块。速览投影包含已保存的受限信息块顺序、独立排列 revision 与可编辑标记；窗口自身不读取配置文件。直接拖动、自动保存、取消、冲突及键盘行为见 [自定义速览](glance-information-blocks.md)。系列数据最多七个公开日期与 tokens 数值，带估算和完整性标记；默认组合在 360×520 内保留两个额度环、三项消耗和两条状态。更多内容滚动，不缩小核心数字。

## 布景快捷恢复（2026-10-22）

外观摘要根据检测结果提供“启动并应用布景”“重启并应用布景”或“应用已保存布景”。未选择应用时进入主窗口选择，后台忙时隐藏快捷动作并显示处理进度。通过启动/重启连接成功后自动应用、验证已保存布景；主窗口未保存草稿不参与。所有图层关闭时只建立连接，不虚报已应用。

`appearanceQuickAction` 仅接受严格的 action 枚举，由宿主核对外观模块运行状态、当前公开动作与任务占用后固定映射。重启通过原生确认，确认期间保持面板打开；取消不退出目标，设置或状态变化拒绝继续，重复请求拒绝。返回值只有 started/cancelled，完成结果通过已有公开摘要呈现，完整任务/配置接口仍拒绝速览调用。原生确认只授权正常退出，不强杀。

检测在启用、主窗口聚焦、速览打开和可见期间进行，三秒节流且避让任务；只读所选包匹配的进程参数，在后台提取端口并进一步验证可识别主窗口。隐藏速览后计时器清理，原有已应用布景的同步生命周期独立保持。进程信息与路径不进入投影、诊断或 renderer。
