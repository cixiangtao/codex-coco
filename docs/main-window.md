# 正式主窗口

日期：2026-10-21。Mode：Operate。精简侧栏方向已获用户认可，本轮将其接入真实 Electron 入口。

## 已实现

`pnpm run dev` 开发运行，或 `pnpm run build` 后执行 `pnpm run start` 打开生产文件。菜单“文件 → 新建窗口”可以新建主窗口。窗口默认进入外观页，提供用量、外观、模块管理、设置四个入口。

侧栏固定为 56px 图标栏。常用模块在上，管理设置在下，保留键盘操作与当前页标记。鼠标悬停 300ms 后在右侧显示带圆角和小箭头的主题提示，相邻菜单连续悬停时立即切换；键盘聚焦也显示，Esc 或点击关闭。图标保留可访问名称，移除原生 title 避免双重提示。设置图标上的小点表示未保存的主题预览。

macOS 标题栏使用 hiddenInset 与原生窗口按钮，网页只实现拖动区域，不再提供导航展开/收起控件。实现参考 [Electron 自定义标题栏文档](https://www.electronjs.org/docs/latest/tutorial/custom-title-bar)。

标题栏与左侧栏使用连续的中性背景。内容区为 12px 圆角的独立表面，右侧和底部留 8px 间距；浅色使用偏白色，深色跟随共享主题。只有内容区滚动，外壳与底部导航固定可达。

设置页提供真实的浅色/深色/跟随系统、配色预设和自定义主色。预览、取消、保存、跨窗口冲突及重启恢复继续使用既有 SettingsStore 和白名单桥；设置写入仍只允许主窗口。

主题编辑状态由 App 级 hook 持有，各页面保持挂载并通过 hidden 切换；切换导航不会丢失无效颜色输入或未保存草稿。切走设置后，标题栏提示仍在预览主题；只有保存才广播。恢复提示可以在设置之外显示，普通主题操作反馈留在设置页。

模块管理读取真实宿主快照。业务注册表为空时，说明用量与外观尚未接入，没有启用或连接按钮。只有宿主显式注册的模块才有真实操作。合成验证模块仍仅在未打包且 CODEX_COCO_FIXTURES=1 时出现，入口位于模块管理页。

## 边界

当前可使用的是主窗口与设置，尚未实现真实账号读取、用量更新、外部 Codex 连接/布景应用。菜单栏现已提供只读状态速览与页面跳转。外观页可以进入 Codex Coco 自身主题设置，用量页可以进入模块管理；不会把这些跳转描述成业务功能完成。

独立窗口方案评审页保留三种布局、示意布景和跨模块悬浮窗，使用合成数据。它与正式主窗口是独立入口。图标、签名、公证和发布仍待后续。
